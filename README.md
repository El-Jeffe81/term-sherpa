This repo is a tool to read and understand terms and conditions, as well as potential risks for human interaction with technology.

The idea is to find the gotchas, the loopholes, the unforeseen consequences of interacting with websites, applications, apps, etc.

## Term Sherpa browser extension (prototype)
`prototype/` holds a free browser extension that explains terms, privacy policies and "I agree" dialogs on your device, with fixed rules (no AI, no network for the analysis).
One source builds a Chrome-family package and a Firefox package (`cd prototype && npm run build`).
